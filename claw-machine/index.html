    Teacher setup

    Quick setups

    Toys in the machine

    Turn on the toys to use, then set how many of each. A toy that is on with 0 still shows in the guesses and the tally, which is good for "impossible".

    Rules

    On: the machine always has the same toys (with replacement). Off: grabbed toys stay out, so the chances change (without replacement).

    Share this setup

    Students who open this link get the same machine.

    Settings

    One Grab button works with one tap, one key or one switch. "Move the claw" adds left and right buttons (or the arrow keys). The toys are mixed up, so every toy has a fair chance either way.

    Says which toy the claw grabbed. Screen reader users hear the same words from VoiceOver or ChromeVox, so you can turn this off for them.

    Off: calm mode. The claw jumps straight to each step with no sliding or swinging.

    Play full screen

    This browser cannot hide its own address bar, so the game has hidden its buttons instead. Use Exit full screen in the corner to get them back.

    For true full screen on an iPhone or iPad, add the game to the Home Screen once. It then opens full screen every time.

    1. In Safari, tap the Share button (the square with an arrow). On a newer iPhone it may be under the ⋯ button.
    2. Tap Add to Home Screen, then Add.
    3. Open Claw Machine from the Home Screen.

    For a locked-down lesson, turn on Guided Access in iPad Settings under Accessibility, then triple-click the top or Home button inside the game.
