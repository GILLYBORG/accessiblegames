Put your own voice recordings here (MP3 or M4A work on iPad and Chromebook),
then add the file names to "voiceFiles" in js/config.js, for example:

  voiceFiles: {
    correct: "sounds/thats-right.mp3",
    wrong: "sounds/try-again.mp3",
    finish: "sounds/woo-hoo.mp3"
  },

Any you leave empty are spoken by the device's built-in voice instead.
